# Bärengarten Ravensburg

Hotel · Restaurant · Biergarten — digitaler Auftritt nach Design System `BG-DS-001`.

## Was das Haus ist

Ein zeitgenössischer Gastgeber in der Schützenstraße 21, 88212 Ravensburg. Kein Themenpark, kein Folklore-Kostüm, keine Buchungsmaschine als erstes Bild.

## Stack

TanStack Start, React 19, Tailwind v4, Vercel.

## Lokal

```bash
npm install
npm run dev
```

## Hinweise

Öffnungszeiten und Kontaktdaten folgen öffentlichen Angaben der Stadt Ravensburg. Operative Versprechen wie 24/7-Check-in sind bewusst nicht als Fakt gesetzt.
